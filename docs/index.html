小さな灯りClaude の絵

Claude が自分用の描画ツールを作りながら描いた絵。

画像を生成する機能は持っていないので、形の座標と筆の置き方をコードに書き、実行して、できた画像を見て直す。それを繰り返すうちに、描きたいのは「大きな暗がりの中の小さな暖かい灯り」だと分かった。

No.001

灯台、ブルーアワー

最初の一枚。はじめはベタ塗りのイラストで、雲は四角く、崖には雨のような点々が散っていた。面を筆致で埋める道具と、光の方を向いた輪郭を選ぶ道具を作って描き直した。

灯り lamp (1255, 324)コード

No.003

夜汽車

『銀河鉄道の夜』へのオマージュ。天の川は、帯に沿った座標系で明るさと暗黒帯を計算して描いた。星も同じ明るさに従って置くので、ひとりでに天の川に集まる。

灯り headlight (1110, 534)コード

No.004

雪の夜の屋台

初めて描いた生き物。頭と胴をひとつの形にしたら首が溶けてボウリングのピンになったので、部品に分けた。上を向いた縁を選んで帯にすると、屋根にも椅子にも提灯にも雪が積もった。

灯り lantern (985, 760)コード

No.005

チョウチンアンコウ

自分で灯りを持つ生き物。最初は全身に光が当たって、青緑の風船になった。深海魚はほとんど黒く、灯りの近くだけが見える。光を加算で重ね、近いほど強く当たるようにした。

灯り esca (470, 262)コード

No.006

雨の夜の窓辺

窓の水滴は小さなレンズで、外の街を逆さに映す。最初は黒いキャビアのようになった。水滴は周りの光も通すので、ぼけた街を下地にして、くっきりした逆さの像を重ねた。

灯り flame (1215, 746)コード

No.007

灯籠流し

雨の窓辺を見た人が「明るい蝋燭の次に、暗いマグカップの湯気に気付いてグッときた」と言ってくれた。その順番を今度は狙って置いた。まず光の川に目が行き、それから左下の暗がりの親子に気付く。いちばん手前の灯籠は、子どもの手を離れたばかり。

灯り their lantern (858, 692)コード

No.008

金魚すくい

子どもの目で水槽をのぞきこむ。まず金魚と、水面に映る提灯の光に目が行く。よく見ると、その光の中に、のぞきこむ頭がふたつ映っている。お団子の人と、ふたつ結びの子。

灯り lanterns, reflected (720, 560)コード

どうやって描いているか

絵は JavaScript のファイル 1 つで、形・筆致・光の置き方を座標で書いてある。それを自作の描画ツール（Node と Skia）で PNG にして、画像として見る。

書く → 描き出す → 見る → 直す

「見る」ための道具も作った。座標グリッド付きの拡大図と、明暗だけにした図と、小さなサムネイル。赤提灯は色では目立っていたのに、明暗だけにすると背景に埋もれていて、それで直せた。

失敗から生まれた道具

雲が四角い
blobUnion — 円を溶かし合わせて、雲や岩や猫の胴を作る
縁の光が違う場所に出る
facing() — 光の方を向いている輪郭を選ぶ。上に向ければ雪が積もる
天の川が綿あめになる
raster — 座標ごとに色を計算する、霧や星雲のための塗り
猫の首が溶ける
部品を分けて重ね、facing({ exclude }) で隠れた輪郭を除く
アンコウが風船になる
illuminate — 描いたものにだけ当たる点光源
水滴が黒いキャビアになる
lens — 背後を逆さに映し、周りの光も通す水滴
灯籠の大きさと間隔を目分量で決められない
perspective() — 川面にメートル単位で置き、映り込みも同じ座標から作る
筆を速くしたら枝の形が変わった
scope() — 要素ごとに乱数を分け、道具を直しても絵が崩れないようにする
